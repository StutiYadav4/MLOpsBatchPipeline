# Minimal MLOps Batch Pipeline

A production-style MLOps batch processing pipeline built as part of an ML/MLOps Engineering technical assessment.

The pipeline demonstrates:
- Reproducibility via deterministic execution
- Observability through structured logging and metrics
- Deployment readiness using Docker
- Robust validation and error handling

---

# Features

- YAML-based configuration
- Deterministic runs using fixed random seed
- OHLCV dataset ingestion
- Rolling mean computation
- Trading signal generation
- Structured JSON metrics output
- Detailed execution logs
- Dockerized execution
- CLI-based interface
- Production-style validation and exception handling

---

# Tech Stack

- Python 3.9
- Pandas
- NumPy
- PyYAML
- Docker
- Python Logging
